# loot-preview

Dungeon-run Item Previews HUD (top-middle button + Quest Storage-like grid). Loot-lock roll stays in the engine; this mod owns the Lua HUD.

## Needs

1. Moru's fork (`RQ_modding_xsystem4`, `-Dmodloader=true`) — not stock xsystem4 1.0.0
2. `rqmod` apply into a work copy (`rqmod\apply.ps1`)

Local-only git. No remote. Do not push until Moru asks.

Apply discovers this folder as sibling `mods\loot-preview\` next to `rqmod\`.
